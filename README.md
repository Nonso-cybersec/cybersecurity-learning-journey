# Cybersecurity Learning Journey

## About
This repository documents my structured learning path toward 
becoming a SOC Analyst. It covers hands-on labs, completed 
courses, problems solved, and key concepts learned.

**Current Goal:** SOC Analyst role — combining defensive 
security, threat detection, and network fundamentals.

## Why This Journey

I started this path as a Microbiology graduate realising 
that cybersecurity is where I want to build my career. 
Rather than just collecting certificates, I focus on 
understanding concepts deeply enough to teach them — 
and building real hands-on skills through my SOC home lab.

Every entry in this repo answers three questions:
1. What did I learn?
2. What problem did I solve?
3. How does it apply to real security work?
